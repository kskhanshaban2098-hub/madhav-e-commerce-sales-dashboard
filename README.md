# 📊 Madhav E-Commerce Sales Dashboard

## 📌 Project Overview

An interactive **Power BI dashboard** created to analyze Madhav Store's e-commerce sales performance across India.

The dashboard transforms sales data into meaningful visual insights using KPIs, charts, filters, and interactive analysis.

## 🎯 Objectives

* Analyze overall sales and profit performance.
* Identify top-performing products and categories.
* Analyze sales across different states.
* Understand customer purchasing patterns.
* Analyze payment methods.
* Track monthly sales and profit trends.
* Identify areas of strong and weak performance.

## 📊 Key KPIs

* **Total Sales**
* **Total Profit**
* **Total Quantity**
* **Average Order Value (AOV)**

## 📈 Dashboard Analysis

* Sales & Profit by State
* Sales by Category
* Sales by Sub-Category
* Monthly Sales & Profit Trends
* Top Customers
* Payment Mode Analysis
* Quantity & Profit Analysis

## 🚀 How to Use

1. Download or clone the repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Refresh the data if required.
4. Use the slicers and filters to explore the dashboard.
5. Interact with the visualizations to analyze sales performance.
